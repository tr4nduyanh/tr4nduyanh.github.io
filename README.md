# Trần Duy Anh · Behind the screen

My portfolio: https://tr4nduyanh.github.io/

```
index.html       page frame: icons, dialogs, an empty <main> the script fills
css/style.css    all styles, in 18 numbered sections (contents at the top)
js/app.js        content, search, routing and the interactive demos (contents at the top)
img/             photos and screenshots (children's faces blurred)
ASM3/            FUNiX assignment site
```

Plain HTML, CSS and JavaScript. No framework, no build step.
It is a single-page site: `js/app.js` reads the part of the URL after `#`
(for example `#netmo`) and draws that page into `<main>`.

## How it was made

I built this site with help from Claude, an AI assistant by Anthropic.
The projects, photos, writing and facts are mine. Most of the code was
written by AI, shaped through many rounds of my own feedback and decisions.
